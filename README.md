# CV-
基於 Python 與 OpenCV 擷取攝影機串流，結合 Hugging Face Transformers 載入 DETR（DEtection TRansformer）模型執行即時物件辨識，並利用 Pillow 渲染支援繁體中文標籤與半透明互動式篩選選單。


本專案將相機擷取、模型推論、介面互動與視覺渲染解耦為模組化設計。啟動入口支援舊版相容命令：
python op_cv.py
